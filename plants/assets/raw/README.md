# Your plant photos

Drop **JPG or HEIC** files here, then run from `plants/`:

```bash
npm run ingest:photos
```

**Filenames** (any one per plant):

| Plant | Filenames |
|---|---|
| Bird of paradise | `bird-of-paradise.jpg` or `1.jpg` |
| China doll | `china-doll.jpg` or `2.jpg` |
| Olive tree | `olive-tree.jpg` or `3.jpg` |

Photos auto-rotate if they were taken sideways on a phone.

Output: optimized JPGs in `public/demo/` used by the demo seed data.

**Tip:** Drag files into this folder in the Cursor file tree — chat attachments don't always reach the workspace.
